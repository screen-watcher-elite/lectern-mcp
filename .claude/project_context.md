# Lectern MCP — Claude Code Project Memory

## Core Details
- **Project**: Lectern MCP (University Curriculum & Viva Examiner)
- **Author / Maintainer**: `screen-watcher-elite`
- **Target Repository**: `https://github.com/screen-watcher-elite/lectern-MCP`
- **Primary Use Cases**: Oral examination practice, engineering curriculum mapping, previous year question retrieval, local lecture note search.

## Tools Summary
1. `generate_viva_defense`: Simulates oral viva examination with rigor score (1-10), hand-waving detection, and counter-questions.
2. `query_syllabus_pyq`: Curriculum learning outcomes, recommended textbooks, and 5/10-mark PYQs.
3. `synthesize_cheat_sheet`: High-density exam formula sheets for Linear Algebra and Optimization.
4. `index_lecture_notes`: Search and extract formulas from local `.md`, `.txt`, and `.tex` notes.
5. `evaluate_conceptual_gap`: Diagnoses misconceptions with concrete geometric counter-examples.
